# Shard manifest template

`large-scale-changes` opens this when it splits the change into shards, fills
one row per shard before asking the user whether to open them, and updates
each row's state and link as shards open and merge; the final report is this
file. Write it to `.sdlc-skills/designs/{{YYYY-MM-DD}}-{{topic}}-shards.md`
unless the user names another place; the user's open-all or pilot-first
answer is a row in the ledger beside it. No secret or credential goes in it.
An empty section means the thing was not run, not asked, or not known, so
say which; the change is not done while any row's state is not merged.

```markdown
# Shard manifest — {{change-short-name}}

- **Change:** {{from what, to what, over which paths, in one sentence}}
- **Predecessor:** {{an earlier manifest for the same change, or none}}
- **Script:** {{path and revision of the script; the test fixtures beside it}}
- **Base:** {{branch and revision the shards target}}
- **Owner:** {{who answers the open-all or pilot-first question}}
- **Status:** `{{scripted | sharded | pilot-open | open | merged}}`
- **Decision ledger:** {{the ledger path beside this manifest and the identity of the open-all or pilot-first row; "no row" until decided}}
```
